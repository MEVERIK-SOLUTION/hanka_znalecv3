# Changelog

Všechny významné změny v tomto projektu budou dokumentovány v tomto souboru.

Formát vychází z [Keep a Changelog](https://keepachangelog.com/cs/1.0.0/),
a tento projekt dodržuje [Sémantické verzování](https://semver.org/lang/cs/).

## [3.0.0] - 2026-02-15

### Přidáno
- Profesionální reorganizace struktury projektu
- Nová adresářová struktura (website/, assets/, pages/)
- Oddělené CSS, JS, a data do příslušných složek
- Komplexní README s instrukcemi pro vývoj a nasazení
- Package.json pro moderní webový vývoj
- .gitignore pro běžné soubory
- Meta tagy pro SEO optimalizaci
- Open Graph tagy pro sdílení na sociálních sítích
- Favicon (SVG) pro lepší branding
- Smooth scrolling a animace pro karty
- Přechodové efekty (transitions) pro lepší UX
- Detailní JSDoc dokumentace pro všechny funkce
- Vylepšená dokumentace v JavaScript souborech
- CONTRIBUTING.md s pokyny pro přispěvatele
- LICENSE soubor (ISC)
- CHANGELOG.md pro sledování změn
- Utility CSS třídy pro častá použití
- Lepší responzivní design pro mobilní zařízení
- Print styly pro tisk dokumentů
- Zlepšená přístupnost (accessibility)
- Lepší error handling v JavaScriptu

### Změněno
- Modernizovaný font stack pro lepší renderování
- Vylepšené barvy a přechody
- Optimalizované CSS s CSS proměnnými
- Refaktorovaný JavaScript s lepší strukturou
- Zlepšená bezpečnost (XSS prevence)
- Aktualizované cesty k souborům
- Vylepšený kalkulátor s lepší validací

### Opraveno
- Opraveny relativní cesty k assets
- Konzistentní cesty napříč všemi stránkami
- Správné odkazy na obrázky
